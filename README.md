# TEK
(This document was generated by AI.)
TEK is a research-oriented **delta-f gyrokinetic particle-in-cell (PIC) code** for low-frequency electromagnetic turbulence in tokamak plasmas. The main executable is written in modern Fortran and parallelized with MPI. The code advances gyrokinetic markers for all configured species; the electron finite-Larmor-radius (FLR) response can be disabled to obtain the zero-Larmor-radius electron model. An optional fully kinetic (FK) ion path is also present.

The repository contains the solver, sample equilibria and profiles, benchmark configurations, cluster build/run scripts, and a small collection of diagnostic and preprocessing utilities.

## Quick start

### Dependencies

A working build requires:

- an MPI Fortran compiler (`mpif90`, Intel MPI `mpiifort`, or a site equivalent);
- FFTW 3, including the Fortran 2003 interface file `fftw3.f03`;
- BLAS and LAPACK.

The checked-in `makefile` contains machine-specific branches for several clusters and a Linux fallback. The fallback currently uses hard-coded library paths that may not exist on another system. On a conventional Linux installation, the portable override below is usually the simplest starting point:

```bash
make compile_one_file \
  lapack_location=-llapack \
  blas_location=-lblas \
  fftw_lib=-lfftw3
```

This creates the executable `TEK` and an intermediate concatenated source file `TEK_in_one_file.f90`.

### Run

Run from the repository root, because `main.f90` opens `input.nmlt` and all relative data paths from the current working directory:

```bash
mpirun -n 512 ./TEK
```

The sample `input.nmlt` uses 16 poloidal tubes, so the MPI process count must be divisible by `ntube`. It also requires `(mpol - 1) / (numprocs / ntube)` to be an integer. Start with a process count and grid that satisfy both constraints; see [Build and run](docs/build-and-run.md) for the complete checklist.

## What is in this repository?

- `main.f90` — MPI initialization, namelist loading, equilibrium/coordinate setup, marker initialization, Runge–Kutta time loop, field solves, diagnostics, and restart dispatch.
- `modules.f90` — shared constants, normalization values, grid/equilibrium state, MPI decomposition state, control parameters, and perturbation-field arrays.
- `equilibrium.f90`, `magnetic_coordinates.f90`, `mapping.f90` — G-EQDSK ingestion, magnetic surfaces, coordinate construction, metrics, and cylindrical/magnetic-coordinate mapping.
- `gk_module.f90`, `load_gk.f90`, `gyro_ring.f90`, `gyro_average.f90`, `drift.f90`, `push_gk_orbit.f90`, `push_gk_weight.f90`, `deposit_gk.f90` — gyrokinetic marker storage, loading, gyro-averaging, characteristics, weight evolution, and deposition.
- `poisson.f90`, `gk_polarization.f90`, `ampere.f90` — electrostatic and electromagnetic field solvers.
- `boris.f90`, `force.f90`, `push_fk_orbit.f90`, `push_fk_weight.f90`, `deposit_fk.f90` — optional fully kinetic ion orbit and weight path.
- `diagnosis.f90`, `restart.f90`, `filter.f90`, `transform.f90` — diagnostics, binary restart files, filtering/smoothing, and FFT/DST support.
- `cbc/` and `itpa_ep/` — example equilibria, radial profiles, case inputs, and cluster scripts.
